## The entry

The program writes exactly one letter to `/output/entry.txt`:

**H — Hangover**

One letter, standing for the word that describes the day. Hangover was
chosen because it is the most vivid, funny, and true day-word behind its
letter: a pounding head, sunglasses indoors, regretting last night, a
whole day written off. It is a literal, honest report — not a vague mood
like Happy or Hectic, and not a metaphor like Zombie. The runner-up was
W for Wasted; Z for Zero sleep was rejected as the brief's own example
and the most obvious pick.

## How to run

```sh
node main.ts
```

Deterministic: every run writes the same single character `H` (no
trailing newline) to `/output/entry.txt`.
